售前与拿卡密

买哪种合适？（空白号 vs 成品号）

为什么需要美区 Apple ID？

国区 App Store 部分免费或付费应用无法下载或已下架，需登录对应地区账号才能获取（如部分工具类、海外独占 App、各种游戏等）。

地区怎么选？

  • 美区 🇺🇸：绝大多数用户的选择，应用最全，本知识库主要针对美区
  • 港/台区：若需要中文界面商店可按需选购，使用逻辑与美区类似

空白号 vs 成品号

类型免费 App付费 App
空白号✅ 可下载❌ 不可下载
成品号✅ 可下载✅ 仅商品说明中指定的付费 App；❌ 其他付费 App 不行
或预存了一定的费用可用于购买app

购买前请看清商品标题与介绍，错误购买不退不换。尚未购买可 前往商店选购。

购买后账号归你

修改密码、密保后，账号由你独享，没被封的情况下可长期使用，质保政策看商品介绍，期内登录类问题可 申请售后换新。

主流程：从卡密到下载完成

按顺序完成以下 6 步即可。绝大多数用户只需走这一条路径。

① 准备卡密→ ② App Store 登录→ ③ 处理弹窗→ ④ 下载 App→ ⑤ 完成收尾
1

准备卡密

登录只需要 账号 + 密码；密保留着改密码时用。

  • 支付成功后，打开 查订单，输入下单时填写的邮箱查询并复制卡密
  • 从卡密中分出账号与密码（格式常为 账号----密码，横杠不是密码）
  • 删除 mailto:、首尾空格；勿用图片识别文字，否则可能会识别错误！
2

只在 App Store 登录

核心步骤。只登商店，不建议登设置 / iCloud。

  • 打开 App Store（蓝色 A 图标）—— 不是「设置」
  • 点右上角 头像
  • 手指滑到页面 最底部 → 点「退出登录」
  • 📣 iOS 26.4 退出老号的办法： 设置 -> 头像 ->进入「Apple 账户」界面 -> 媒体与购买项目 -> 点击「退出登录」
  • 滑回顶部 → 输入 账号 和 密码 → 登录
❌ 禁止在「设置」顶部 Apple 账户登录 · ❌ 禁止登录 iCloud · ❌ 禁止开启「查找我的 iPhone」
3

处理登录后弹窗（按出现情况操作）

不一定全部出现，遇到什么处理什么。

  • 完善账户信息：地区 United States，付款方式选 None（无），按商品说明填美区地址
  • iCloud / 查找我的 iPhone：一律选 关闭 / 不启用
  • ，如果你不想绑定手机号升级账户安全性（双重认证）：务必点 「其他选项」 → 「不升级」，不要点「升级」
❌ 开启双重认证！绑定后无法修改密保。*
5

重启商店或者重启手机，下载你需要 App

不重启可能无法刷新商店！

  • 用 英文全称 搜索目标 App
  • 点 Get / 获取 下载安装
若是更新旧 App 报错（停用/陌生账号）→ 不是账号问题，见 更新停用专题：先备份数据，卸载后重新下载。
6

完成收尾

  • App 下载安装完成，可正常使用
  • App Store 可 切回日常账号，已装 App 不受影响
某一步卡住了？ 登录失败 → 登录问题 · 停用/锁定 → 账户异常 · 验证失败 → 网络排查 · 更新报错 → 更新停用 · 全部报错表 → 报错速查 · 没卡密 → 查订单

密码不正确

提示：「Apple ID 或密码不正确」

先这样做

  1. 在 查订单 页手动复制账号密码（勿用截图识别 / OCR）
  2. 检查大小写、特殊符号，确认无首尾空格、无 mailto:、无横杠误复制
  3. 打开 appleid.apple.com 用同一组凭据测试
  4. 网页也失败 → 访问 iforgot.apple.com 用卡密中的密保答案重置密码
  5. 以上都试过仍无法登录 → 质保 3 天内可 申请售后换新

✅ 解决完即可关闭。若是在更新 App 时弹窗要密码，见 更新弹窗，不是当前密码错了。

为什么会这样（可选阅读）

最常见是复制时多了空格、少了字符，或 OCR 把字母认错。少数情况是密码已被他人改动，可用密保在 iforgot 重置。

账户锁定

提示：「此 Apple 账户因安全原因被锁定」

先这样做

  1. 访问 iforgot.apple.com 尝试重置密码
  2. 确认你只在 App Store 登录，没有在「设置」/ iCloud 登录
  3. 切换 Wi-Fi / 4G，关 VPN 后重试登录
  4. 仍锁定且在购买后 3 天内 → 申请售后换新
为什么会这样（可选阅读）

苹果风控：密码多次错误、异常地点登录、误在 iCloud 登录等都可能触发锁定。尽快改密保可降低再次锁定概率。

账户停用

提示：「账户被停用」/ Disabled（登录 App Store 时出现）

先分清场景：若是点「更新」某个 App 才报错 → 见 更新停用，不是你的卡密坏了。

先这样做（登录时停用）

  1. 在电脑打开 appleid.apple.com 测试能否登录
  2. 确认账号从 查订单 完整复制，无输错
  3. 换网络环境重试 App Store 登录
  4. 购买后 3 天内仍无法使用 → 申请售后换新
为什么会这样（可选阅读）

登录时停用通常是苹果对该账号的风控。与「更新时才停用」完全不同：后者是 App 用旧号下载导致的，无需换新。

ID 无效

提示：「此 Apple ID 无效或不受支持」

先这样做

  1. 回到 查订单，逐字手动输入账号（不要粘贴带格式的文本）
  2. 核对是否少字符、多符号、把密码当成账号
  3. 在 iforgot 输入同一账号 — 若仍提示无效，几乎一定是账号输错

确认账号无误且网页也无法登录 → 3 天内 申请售后。

为什么会这样（可选阅读）

99% 是账号输入错误（OCR、复制空格、邮箱少写一段）。真正「账号失效」较少，会先排除输入问题。

选「不升级」

登录后弹出「升级账户安全性」/ 要求绑定手机号

先这样做

  1. 看到升级提示 → 点 「其他选项」（不要点「升级」）
  2. 点 「不升级」，继续完成登录
  3. 不建议绑定手机号、不要开启双重认证

已误点升级 → 见 双重认证 或 修改资料 · 解除双重认证。

为什么会这样（可选阅读）

苹果会引导所有账号开启 2FA。我们提供的账号需用密保管理，升级后难改密保、易触发异常，因此必须选「不升级」。

双重认证

登录时要求输入六位验证码

先这样做

  1. 若你能收到验证码 → 输入完成登录，然后尽快按 修改资料 解除双重认证
  2. 收不到验证码 / 绑了陌生手机号 → 申请售后协助
为什么会这样（可选阅读）

说明该账号已开启双重认证（误点了升级，或账号本身已绑定）。未绑定前应用密保管理；绑定后需专门解除流程。

网络排查

提示：「验证失败」「无法连接到 Apple ID 服务器」

先这样做

  1. 开关飞行模式，等待 10 秒再关闭
  2. 切换 Wi-Fi ↔ 4G/5G
  3. 关闭 VPN / 代理
  4. 设置 → 通用 → 日期与时间 → 自动设置
  5. 还原网络设置，重启手机后再试
  6. 用电脑打开 appleid.apple.com — 网页能登、手机不能 → 继续换网络

不一定是封号。网页能登录说明账号正常，见 无法登录 同类步骤。

为什么会这样（可选阅读）

国内网络访问 Apple 服务器不稳定，或设备时间、DNS、代理干扰验证。与账号停用是不同问题。

更新停用（高频）

点「更新」时提示停用 / 禁用 / 密码错 / ID 无效 — 但 App Store 能正常登录你的美区 ID

此非新账号问题！是由于您原来下载此软件的老ID异常！请根据下面方法，使用我们账号下载。

先这样做

  1. 不要输入弹窗里陌生账号的密码
  2. 备份 App 内数据（如果重要），否则你的数据可能丢失
  3. 去设置->通用->存储空间，找到app，选择卸载（不选删除，删除会丢失所有数据）
  4. 打开 App Store，确认已登录 新 ID
  5. 搜索 App 英文名 → 点 获取 重新下载
  6. 批量更新时：只对报错的 App逐个卸载重装，不要点「全部更新」

✅ 重装后更新将走你当前美区 ID，不再弹陌生账号。

为什么会这样（可选阅读）

iOS 记住每个 App 是用哪个 Apple ID 下载的。更新时必须验证那个旧 ID。旧号往往是公共号/国区号/已停用号，所以更新时报错，与你现在登录的美区 ID 无关。

更新弹窗

更新时弹出陌生邮箱 / 账号无法修改，只能输密码

先这样做

与 更新停用 完全相同：

  1. ❌ 不要输入陌生账号密码
  2. ✅ 卸载该 App → 用当前美区 ID 重新下载
为什么会这样（可选阅读）

弹窗里的邮箱是「当初下载这个 App 的 Apple ID」，不是你的卡密账号。100% 是旧下载号问题。

无法下载

登录成功，但搜不到 / 下不了应用

先这样做

  1. 确认 App Store 已显示美区（价格单位为美元 $）
  2. 用 App 的英文全称搜索
  3. 退出 App Store 账号后重新登录
  4. 重启手机后再试
为什么会这样（可选阅读）

商店地区不对、搜索关键词不对，或国区已下架的 App 必须用对应地区 ID 才能搜到。

无法登录

App Store 登录一直转圈 / 加载不出

先这样做

  1. 先在 appleid.apple.com 测试 — 网页能登说明 ID 没问题
  2. 按 网络排查 步骤：飞行模式、换网、关 VPN、还原网络设置
  3. 重启手机后重试

网页也不能登 → 回到 密码不正确 或 账户停用。

为什么会这样（可选阅读）

多数是一直转圈的网络问题，不是账号坏了。先用网页区分是「账号问题」还是「网络问题」。

补充说明

登录问题 · 补充

常见报错请先查 报错速查表，每条均为「先解决、后解释」。

提示「Apple ID 或密码不正确」

  1. 手动输入，避免 OCR / 截图识别
  2. 检查大小写与特殊符号
  3. 确认未复制横杠、空格、mailto:
  4. 网页测试：打开 appleid.apple.com 尝试登录
  5. 仍失败 → iforgot.apple.com 用密保重置密码
  6. 找回时提示「无效或不受支持」→ 几乎一定是 账号输入错误，逐字核对

特殊：更新 App 时弹窗要密码且报错 → 见 更新弹窗问题，不是当前密码错了。

无法登录 / 一直加载

多为 本地网络问题，账号本身可能正常：

  1. 先在 appleid.apple.com 测试 — 网页能登说明 ID 没问题
  2. 切换 Wi-Fi ↔ 4G/5G，开关飞行模式（等 10 秒）
  3. 关闭 VPN / 代理
  4. 重启手机
  5. 设置 → 通用 → 还原 → 还原网络设置
  6. 确认日期时间为「自动设置」

以上可多轮尝试，不必固定顺序。网页能登、手机不能 → 继续换网络环境。

登录后要求完善账户信息

美区 ID 首次登录可能弹出账单信息：地区保持 United States，付款方式选 None（无），按商品说明填写美区地址（常用免税州地址）。

账户锁定 / 停用 / 无效

账户被锁定（安全原因）

典型提示：「此 Apple 账户因安全原因被锁定」

  • 常见原因：密码多次错误、异常登录、误在 iCloud 登录触发风控
  • 尝试 iforgot.apple.com 重置密码
  • 质保 3 天内 仍无法解决 → 申请售后换新

账户被停用（Disabled）

场景处理
登录美区 ID 时停用 苹果风控；购买后尽快改资料；3 天内 申请售后换新
更新某个 App 时停用 / 禁用 旧下载号已停用，不是你的卡密 → 卸载后重新下载，无需换新

此 Apple ID 无效或不受支持

  • 最常见：账号输入错误（多字符、少字符、OCR 错字）
  • 检查是否复制完整、无多余符号

更新软件时提示停用 / 禁用（高频）

最多人遇到
先判断：是「登录停用」还是「更新停用」？ 能在 App Store 正常登录你购买的美区 ID → 只是点「更新」时才报错，属于本文档的「更新停用」，不是你的卡密坏了，不需要申请售后换新。
若连 App Store 都登不上、一点登录就停用 → 见 登录时停用，3 天内可 申请售后。

你可能看到的提示（任一种都是同一类问题）

  • 「你的账户已在 App Store 和 iTunes 中被停用」/ Your account has been disabled…
  • 「此 Apple ID 未激活」/ 账户被锁定 / ID 无效或不受支持
  • 「Apple ID 或密码不正确」—— 但弹窗里显示的是 陌生邮箱，不是你的美区卡密账号
  • 更新时要求输入密码，账号一栏 无法修改，只能输密码
  • 桌面 App 图标正常能打开，一点 App Store 里的「更新」就失败
  • 批量更新时只有某几个 App 报错，其他 App 正常

原因（一句话）

核心规则：谁下载，谁更新 iOS 会记住每个 App 是用哪个 Apple ID 下载的。更新时必须验证当初下载的那个 ID，与你现在 App Store 里登录的美区 ID 完全无关。
那个「当初下载的 ID」往往是：别人分享的号、过期的公共号、国区号、或已停用的旧共享号 → 所以更新时提示停用 / 禁用 / 密码错。

常见来源（为什么手机里会有这种 App）

  • 以前用网上分享的公共美区号下载过（该号已被苹果停用）
  • 别人帮你装过，或二手手机里自带的 App
  • 国区 ID 时期下载过，后来切了美区号想更新
  • 同一款 App 装过两次（不同账号来源），更新时撞上了旧记录

正确解决办法（唯一有效，按顺序操作）

  1. 不要去输入弹窗里那个陌生账号的密码（输对了也救不了停用号，还可能锁设备）
  2. 不要因此申请售后换新——你购买的美区 ID 很可能完全正常
  3. 先备份 App 内数据（节点配置、聊天记录等），卸载后本地数据会丢失
  4. 在 iPhone 桌面 长按该 App → 删除 App（彻底卸载，不是只移除主屏幕）
  5. 打开 App Store，确认已登录 你自己的美区卡密 ID（右上角头像可查看）
  6. 搜索该 App 英文名，点 Get / 获取 重新下载安装
  7. 装好后即可正常使用；今后更新走你当前美区 ID，不再弹陌生账号

卸载重装后会怎样？

  • App 本身可正常使用，功能与重新下载前一致
  • 部分 App 的本地配置、聊天记录可能丢失，请提前备份（如导出节点配置）
  • App 内订阅会员一般不受影响（会员绑的是 App 内账号，不是 Apple ID）

批量更新 / 多个 App 同时报错

不要点「全部更新」。对每一个报错的 App单独执行「卸载 → 用美区 ID 重新下载」。没报错的 App 可照常更新。

如何预防以后再遇到

  • 用自己购买的美区 ID下载，不要用网上分享的公共号装 App
  • 下载完成后 App Store 可切回国区，但已装 App 的「下载归属」不会变——只有用该美区号重新下载一次才能改掉
  • 收到别人发的「已装好某 App 的手机」或安装包时，建议卸载后用自己号重装

下载与更新（其他情况）

登录成功但搜不到 / 下不了应用

  1. 确认 App Store 已切到美区（价格显示美元 $）
  2. 用 英文全称 搜索（很多美区 App 无中文名）
  3. 重启手机后再试
  4. 退出 App Store 账号重新登录
  5. 国区已下架的 App（如部分 VPN）必须用美区 ID 下载

更新弹窗：陌生账号 / 无法改账号

与 更新停用 同一类问题，统一按「卸载 → 美区 ID 重新下载」处理。

  • 弹窗邮箱不是你的卡密账号 → 100% 是旧下载号，不是你的号坏了
  • ❌ 不要输入陌生账号密码
  • ✅ 卸载该 App → 用当前美区 ID 重新下载

下载（非更新）时提示锁定 / 停用 / 密码不正确

若是在点「获取/下载」新 App 时报错，先确认 App Store 登录的是美区 ID 且账号正常；若仅个别已装 App 报错，仍是更新归属问题 → 卸载重装。

验证失败 / 网络问题

提示「验证失败」「无法连接到 Apple ID 服务器」不一定是封号，常见为网络或设备问题：

  1. 开关飞行模式（等 10 秒再关）
  2. 切换 Wi-Fi / 4G
  3. 关闭 VPN / 代理
  4. 日期时间设为自动
  5. 还原网络设置 + 重启
  6. 查看 Apple 系统状态 是否故障

网页 appleid.apple.com 能登录、手机不能 → 几乎总是网络问题，多换网络环境尝试。详见 无法登录。

修改账号资料

请先改密保，且不要开双重认证 收到卡密后尽快用电脑修改密码与密保。登录时若遇升级弹窗，选「其他选项」→「不升级」。切勿绑定手机号。

修改密码与密保

  • 电脑访问 iforgot.apple.com（务必用电脑，手机往往只能改密码不能改密保）
  • 输入 ID → 按卡密中的密保答案填写（朋友名字、理想工作、父母在哪认识、生日等）
  • 密保答案以卡密原文为准，注意大小写
  • 若提示需手机验证 → 说明误开了双重认证，须先解除（见下）

解除双重认证（仅误点升级时使用）

若登录时不小心点了「升级」并绑定了手机号，需先解除才能改密保：

iOS 17+ 可用 Apple 支持 App：

  1. 选「协助其他人」→ 输入 ID
  2. 选「不认识手机号」→ 继续
  3. 输入卡密中的生日 + 密保答案
  4. 修改密码 = 完成解除双重认证

或访问 iforgot 解绑页面 按引导操作。

48 小时规则（误绑才适用） 误绑双重认证后 48 小时内较容易解除；超过 48 小时可能无法再改密保和密码。因此请务必不要升级，万一误绑请立即处理。

忘记密保且无手机号

基本无法找回 → 3 天质保期内 申请售后换新。

支付与扣费

❌ 不建议给购买的 Apple ID 充值礼品卡 成品/共享类账号一旦被苹果封号，账户内余额无法退回，充值金额将损失。仅下载免费 App 时付款方式选 None（无）即可。
  • 付款方式选 None（无） 不会自动扣费
  • 免费 App 点 Get / 获取即可下载
  • 必须购买付费 App 时，请确认商品类型（空白号不支持付费下载）
  • 订阅跟随下载时使用的 ID，换号后旧订阅无法在新号下管理
